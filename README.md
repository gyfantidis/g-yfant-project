## What is this?

Visitors don't land on a typical page. They boot into a terminal — watching a typewriter sequence fire up — then arrive at an interactive desktop with draggable, resizable app windows. Each window is a section of the portfolio.

## App Windows

| Window | Contents |
|--------|----------|
| About | Bio, work experience, education |
| Projects | Selected work & open source |
| Skills | Tech stack and tools |
| Terminal | Interactive CLI with real commands |
| Photos | Personal photo gallery with lightbox |
| Books | Reading list |
| Certifications | Professional certifications |
| Contact | Contact form |
